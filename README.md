# OFAC Automation

Windows desktop app for screening names against OFAC's SDN and Consolidated Non-SDN lists and downloading a PDF record for each result.

## Run a check

Paste names or import a TXT or CSV file, then click **Run Check**. Click **Cancel Check** to stop. Completed results and PDFs stay available until you start another check or close the app.

Each run downloads both lists from the [OFAC Sanctions List Service](https://ofac.treasury.gov/sanctions-list-service) and checks the batch locally. The app retries temporary download failures and waits for both lists before screening names.

The app compares names and aliases after normalizing Unicode, case, punctuation, and spacing. Potential matches need review. Each PDF is generated by the app and includes the source publication dates and matching method.

## Run From Source

```powershell
py -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m playwright install chromium
.\venv\Scripts\python.exe app.py
```

## Build Installer

Install Inno Setup 6, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

The installer is created at:

```text
installer\OFAC-Automation-Setup.exe
```
