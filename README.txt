OFAC Automation
===============

How to use it
-------------
1. Open OFAC Automation.
2. Type names into the Names box, or click Import to load a TXT/CSV file.
3. Click Run Check.
4. Click Cancel Check to stop and keep the results completed so far.
5. Click Resume Check to continue with the remaining names after a pause or cancellation.
6. Use Download on a result row or Download All to keep the PDFs.

PDFs
----
Each PDF prints the actual OFAC Sanctions List Search result page for that name. Download any PDFs you need before starting a new check or closing the app.
